Klimand

One chat. Two agents. Real project awareness.

A local orchestrator UI that drives Claude Code and Codex from a single chat — and actually reads your CLAUDE.md, AGENTS.md, .mcp.json, slash commands, subagents, skills, and hooks before deciding what to do.

npx klimand View on GitHub

Free, open source, local-first

  • Auto-discovers your projects on first run.
  • Routes between Claude Code and Codex based on the actual project config.
  • Threaded chats, scheduled runs, project view, MCP awareness.
  • Apache-2.0. BYOK for the orchestrator.

Pro — coming later

Klimand is free and open source today. A paid Pro tier is planned for solo devs who want the convenience features off their plate. Watch the repo for launch updates.
